# Quiz Application

Welcome to the **Quiz Application**! This project is a simple web-based quiz application built with HTML, CSS, and JavaScript. It allows users to test their knowledge on various topics through an interactive and engaging quiz format.

## Project Files

- **index.html**: The main HTML file that contains the structure of the quiz application.
- **style.css**: The CSS file used for styling the application and enhancing its visual appeal.
- **script.js**: The JavaScript file that handles the quiz logic, including question management and scoring.

## Live Demo

You can view the live demo of the Quiz Application [here](https://website-a369d603.rumennikolaevportfolio.com/).

## Features

- Multiple-choice questions with instant feedback.
- User-friendly interface with responsive design.
- Scoring system to keep track of the user's performance.
